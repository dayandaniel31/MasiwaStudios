Comment ça marche

Du prompt au site.

Qu’est-ce que j’achète ?

Le texte d’un prompt en français. Il sert de brief pour générer et personnaliser un site avec ton outil d’IA.

Comment personnaliser un prompt ?

Copie le texte dans ton outil d’IA. Remplace ensuite les éléments entre crochets par les informations de ton projet, comme ton activité, ton public ou tes couleurs.

Quel prompt choisir pour mon projet ?

Choisis une landing page pour présenter une offre, un prompt e-commerce pour vendre des produits, un portfolio pour montrer tes réalisations ou un site vitrine pour présenter tes services.
